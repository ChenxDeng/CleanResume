# CleanResume

一个单文件的纯前端简历排版工具 —— 打开 HTML 就能写简历、实时预览、导出**可编辑文字**的 A4 PDF。

## 特点

- **零依赖部署**：单个 `index.html`，双击即可用，无需安装任何软件
- **中英双语**：中文（1 页限制）与 English（2 页限制）两套内容独立存储，互不覆盖
- **Markdown 写正文**：用 `##` 章节、`###` 经历行、`-` 列表即可排版，支持 `**加粗**`
- **严格的四级字号体系**：姓名大标题 / 小节标题 / 正文 / 补充信息，第 4 级自动按正文 ×0.9 联动
- **实时调整**：页边距、字号、标题颜色、右上角照片开关，全部所见即所得
- **导出可编辑 PDF**：走浏览器原生打印，导出结果文字**可选中、可搜索、可编辑**，而非图片截图
- **文件名自动合成**：`目标公司_目标职位_姓名_简历`，导出时自动带入
- **本地持久化**：内容保存在浏览器 localStorage，关掉再打开还在

## 使用

1. 用 **Chrome / Edge** 打开 `index.html`（Safari 导出的中文字体在 WPS 里可能无法编辑）
2. 左侧编辑内容，右侧实时预览
3. 顶部填入公司、职位，确认最终文件名
4. 点「导出 PDF（文字可选）」→ 在打印对话框中选择「另存为 PDF」

> 打印对话框中请把「边距」设为**无**、「缩放」设为**默认**，以获得最佳效果。

## 正文 Markdown 语法

```markdown
## 章节标题
### 机构或项目名称 | 时间
- 列表项，支持 **加粗**
```

`###` 行中的 `|` 会被自动识别为右对齐的时间栏。

## 技术栈

原生 HTML / CSS / JavaScript，配合 Tailwind CSS、Font Awesome、Marked.js（均走 CDN）。
