# CleanResume

单文件纯前端简历排版工具 —— 打开 HTML 就能写简历、实时预览、导出**可编辑文字**的 A4 PDF。

## 核心优势：在「简洁」与「简历必要的约束」之间取得平衡

简历排版最常见的失败不是"不够花哨"，而是**自由度太高**：每一份拖出来的排版都不太一样，字号层级随手改，最后输出既不专业也不一致。

CleanResume 的设计取向正好相反 —— **把排版约束得很死，但在真正需要你决定的地方保留控制权**。具体体现在三个方面：

### 1. 输出质量：文字 PDF，而非图片 PDF

导出走的是浏览器原生打印，产出的是**真正的文字 PDF**：

- 文字可选中、可复制、可搜索
- ATS（简历筛选系统）与 HR 能直接解析内容，不会被当成图片跳过
- 文件体积小，缩放不失真

很多在线简历工具导出的是整页截图转成的图片 PDF —— 看起来一样，但机器读不了。

### 2. 排版设置：约束得死，但该能改的都能改

字号被收敛成严格的四级体系，章节结构、行距、缩进、对齐全部锁定，保证输出永远专业、一致：

| 层级 | 用途 |
|------|------|
| 第 1 级 | 姓名大标题 |
| 第 2 级 | 小节标题（带贯穿横线） |
| 第 3 级 | 正文内容 |
| 第 4 级 | 时间 / 地点 / 补充说明（自动按正文 ×0.9 联动） |

在这个框架内，你仍然可以调整：

- **字号**：各级独立滑动调节，并可自定义调节上下限
- **页边距**：上下、左右分别可调
- **标题与姓名颜色**：内置经典黑 / 深蓝 / 深青绿 / 深灰
- **右上角照片**：一键开关
- **页数提示**：中文 1 页、English 2 页，超出版面时有分页参考线提醒

### 3. 操作便捷：Markdown 输入，随时导出本地保存

- 左侧直接写 Markdown（`##` 章节、`###` 经历行、`-` 列表），右侧实时预览
- 无需注册、无需联网、无需安装 —— 单个 HTML 文件，双击即用
- 内容保存在浏览器 localStorage，关掉再打开还在
- 导出文件名自动合成为「目标公司_目标职位_姓名_简历」
- 随时导出 PDF 保存到本地

## 使用

1. 用 **Chrome / Edge** 打开 `index.html`
   （Safari 导出的中文字体在 WPS 中可能无法编辑）
2. 左侧编辑内容，右侧实时预览
3. 顶部填入公司与职位，确认最终文件名
4. 点「导出 PDF（文字可选）」→ 在打印对话框中选择「另存为 PDF」

> 打印对话框中请将「边距」设为**无**、「缩放」设为**默认**，以获得最佳效果。

## 正文 Markdown 语法

```markdown
## 章节标题
### 机构或项目名称 | 时间
- 列表项，支持 **加粗**
```

`###` 行中的 `|` 会被自动识别为右对齐的时间栏。

## 中英双语

中文版与英文版的内容**完全独立存储**，互不覆盖，可随时切换：

- **中文简历**：1 页限制
- **English Resume**：2 页限制

## 技术栈

原生 HTML / CSS / JavaScript，配合 Tailwind CSS、Font Awesome、Marked.js（均走 CDN）。
